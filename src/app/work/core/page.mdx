## Overview

Having successfully developed a highly interactive and user-friendly platform for soccer enthusiasts, CORE approached us to expand their capabilities by creating both a web and mobile application.

The goal was to provide a comprehensive, secure platform that enhances user engagement and offers seamless integration with gaming consoles. The platform needed to facilitate user registration, login, and real-time score displays, while also ensuring a smooth user experience on both web and mobile interfaces.

To achieve this, we built a web application which allows users to register, log in, and generate QR display cards for players, alongside offering score displays with various filtering options. The dynamic and responsive interface of mobile application that supports functionalities such as connecting and disconnecting to a gaming console, manual and QR code-based login, and real-time display of live scores and leaderboards.

By integrating these applications, we provided a secure, user-friendly solution that meets the needs of gaming enthusiasts, ensuring they can easily manage and view their gaming experiences across multiple platforms.
